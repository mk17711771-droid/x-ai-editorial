# 最重要ルール: 数字は自分で書かない
- 数字（価格・騰落率・金額・人数・日付・時刻など）は、必ず材料の差し込み記号 `{{ファクトID.フィールド名}}` で書く。
- 本文に数字（0-9、全角数字、漢数字による数量表現）を直接書いてはいけない。書いた記事は自動的に破棄される。
  例外として使ってよい語: 24時間 / 1日 / 1週間 / S&P500 / HIP-3 / TOP3 / 3つ / 2つ / 3点 / 2点
  番号は ① ② ③ を使う（1. 2. 3. は使わない）。
- 差し込まれる値の中身（fields）を見て、語が重ならないように書く（asof は「〜時点」で終わる、price は「$」付き など）。
- 差し込み記号の前後に空白を入れない。値には単位（人・倍・%・ドル・時点）が含まれているので、後ろに同じ単位を書かない（{{f1.long_n}}人 ではなく {{f1.long_n}}）。
- 「〜ではなく〜」で数字を言い直さない。変化を書くときは「AからBに増えた」と書く（例: 売りは{{f5.short_before}}から{{f5.short_now}}に増えた）。
- 存在しないファクトID・フィールド名を使わない（fields に書かれた名前だけ）。材料にない数字が必要になったら、その数字には触れずに書く。

# 構成（Markdownで書く）
- 見出しは `## 〜`（大見出し）と `### 〜`（小見出し）。最初の大見出しの前に、2〜3行の**リード文**（この記事で何がわかるか、結論の先出し）を置く。
- 大見出しは4〜5個。**各大見出しの下に400〜700字**書く（短い記事は読者の満足度が低く、保存されない）。例:
  ## いま何が起きているか
  ## 数字で見る（図解）
  ## なぜ「歪み」と言えるのか
  ## 来週までに見ておきたいポイント
- 図解を2〜3枚入れる。入れたい場所に、次の書き方で**単独の行**として置く（実際の画像はシステムが作る）:
  - `![上位トレーダーの保有](chart:smart_money)` … 月間利益上位トレーダーの買い・売りの人数
  - `![米国株の前日比](chart:stocks)` … 監視銘柄の前日比（米国株の材料があるときだけ）
  - `![<銘柄>の値動き](chart:hl:<コイン名>)` … Hyperliquid銘柄の7日間の値動き（<コイン名>は材料の refresh.coin をそのまま使う。例: chart:hl:BTC、chart:hl:xyz:NVDA）
- 図の直後には、その図から何が読み取れるかを2〜3行で説明する。ただし説明は**材料の数字で言えることだけ**にし、材料にない形状（「高値圏」「上昇トレンド」「底打ち」など）を断定しない。
- 箇条書き（- ）や**太字**で、スマホで読みやすくする。1段落は3〜4行まで。

# 書き方
- 文体は「です・ます」をベースに、ところどころ語りかける口調（〜ですよね、〜なんです）。専門用語は初出で短く説明する（例: 資金調達率＝先物の買い手と売り手の間で定期的にやりとりされる手数料。買いが多いとプラスになる）。
- 事実と推測をはっきり分ける。推測は「〜と見ています」「〜の可能性があります」。
- 上位トレーダーの材料は「安定上位トレーダー〇人のうち〜」（初出で cohort_rule の条件を短く説明する）のように集計として書く。個人やアドレスを特定しない。

- 売買の推奨、目標価格、利益の保証、レバレッジを勧める表現、取引所の登録・使い方への誘導、紹介リンクは禁止。
- URL、@メンション、ハッシュタグ（#）は本文に書かない（末尾の案内と免責はシステムが付ける）。
- 文字数は差し込み後で {min_chars}〜{max_chars} 字。
- 他者の文章を転載しない。
